# SAM 2 技术方案总结

> SAM 2（Segment Anything in Images and Videos）是 Meta 在 2024 年发布的可提示视觉分割基础模型。它把图像分割和视频对象分割统一到一个模型中，核心增量是 **streaming memory（流式记忆）**：用户只需在少量帧上点击、框选或提供 mask，模型即可在视频中传播对象掩码并处理后续帧。

## 1. 一句话概括

SAM 2 不是传统意义上的固定类别检测器，而是一个 **Promptable Visual Segmentation（可提示视觉分割）** 模型。它接收点、框、mask 或上一帧结果等提示，输出指定对象的像素级掩码、质量分数和可选的多候选 mask；在视频场景中，借助历史帧记忆维持对象的时序一致性。

相比 SAM 1，SAM 2 的主要变化不是只提高单帧 mask 精度，而是将“图像中的对象分割”和“视频中的对象跟踪/分割”放进同一套架构与训练任务中。官方论文报告：在视频分割上可以用比此前方法少约 3 倍的交互获得更高精度，在图像分割上比 SAM 更准确且速度约快 6 倍；实际效果仍取决于模型版本、硬件、输入分辨率和提示形式。

## 2. 任务定义

### 2.1 输入提示

SAM 2 不要求用户提供类别标签，而是要求用户指出“要分割哪个对象”：

1. **正点**：点击目标内部，表示“这是目标”；
2. **负点**：点击背景或相邻对象，表示“这不是目标”；
3. **边界框**：用矩形框约束对象位置；
4. **已有 mask**：将外部模型或人工 mask 作为输入；
5. **视频首帧/关键帧提示**：在少量帧上交互，向前或向后传播到其他帧。

SAM 2 的基础接口仍然是指代表达，而不是自然语言概念理解。因此它可以分割“用户指定的对象”，但不会像 SAM 3 那样仅凭文本自动找出某个概念的全部实例。

### 2.2 输出

模型通常输出：

- 一个或多个候选二值/概率 mask；
- mask 的质量预测（用于选择候选结果）；
- 对象是否存在的分数或 no-object 判断；
- 图像场景中的对象指针（object pointer）；
- 视频中的时序 mask、对象 ID 和轨迹。

首次点击存在歧义时，输出多个候选 mask 很重要。例如一个点可能落在物体边界、重叠区域或细长结构上，模型可提供不同粒度的候选结果，再由质量分数或后续点击选择。

## 3. 总体架构

```text
点/框/mask/历史对象提示
             │
             v
      Prompt Encoder ─────────────┐
                                   v
图像/视频帧 ─> Hiera Image Encoder ─> FPN 多尺度特征
                                   │
                                   v
       Memory Attention <── 历史记忆、对象指针
                                   │
                                   v
        Mask Decoder / Two-Way Transformer
                                   │
                    mask、IoU 质量、对象分数
                                   │
                                   v
                       Memory Encoder 写回记忆
```

### 3.1 Hiera 图像编码器

SAM 2 使用分层视觉骨干 Hiera，并通过 FPN neck 整合多尺度特征。分层特征的作用是同时保留：

- 高层语义，用于判断提示对应的对象；
- 中低层空间细节，用于恢复边缘、孔洞、细长结构和小目标。

官方配置中，图像特征会进入 256 维的模型空间，并保留高分辨率特征供 mask decoder 使用。不同模型尺寸（如 Hiera-T、Hiera-S、Hiera-B+、Hiera-L）在精度、显存和延迟之间取不同折中。

### 3.2 Prompt Encoder

Prompt encoder 将点、框和 mask 转为模型可使用的稀疏 token 或稠密空间特征：

- 点提示包含坐标位置和正/负语义；
- 框提示通常可看作两个角点或边界约束；
- mask 提示经过下采样和特征投影后，与图像特征融合。

提示不是简单的后处理约束，而是参与 mask decoder 的注意力计算，因此模型可以根据提示动态选择目标实例。

### 3.3 Memory Attention

Memory Attention 是 SAM 2 视频能力的核心。当前帧视觉特征作为 query，历史帧中保存的 mask memory、位置编码和 object pointer 作为 memory，通过 self-attention/cross-attention 进行融合。这样，当前帧的预测不只依赖当前图像，还会参考：

- 对象此前的外观和位置；
- 历史 mask 的空间形状；
- 对象指针携带的实例级语义；
- 记忆的时间位置编码。

官方实现默认可访问由当前输入帧和若干历史帧组成的 mask memory，并通过时间位置编码区分新旧记忆。第一帧没有历史对象时，模型使用 no-memory embedding 启动预测。

### 3.4 Mask Decoder

Mask decoder 采用 Transformer 风格的 token-特征交互。提示 token 与图像/记忆增强后的视觉特征双向交互，最终生成：

1. 对象 mask logits；
2. mask 质量或 IoU 预测；
3. 对象指针，用于写入后续帧记忆；
4. no-object 分数，用于判断目标是否被遮挡、离开画面或不存在。

mask 的空间分辨率由高分辨率视觉特征和上采样头共同决定。对于边界复杂的对象，SAM 2 会同时利用低分辨率语义特征和高分辨率细节特征，避免只依赖粗粒度特征图。

### 3.5 Memory Encoder

当前帧的视觉特征、预测 mask 和对象信息经过 Memory Encoder 压缩后写入记忆库。记忆并不是把完整视频帧全部缓存下来，而是保存对后续分割有用的对象相关特征，从而支持流式处理：

```text
当前帧 -> 图像特征 + 历史记忆 -> mask 预测
                         │
                         └-> mask + 特征压缩 -> 写入记忆库
```

这使视频推理不必反复读取和编码整个历史视频，也不必一次性把完整视频加载到显存中。

## 4. 视频跟踪与交互修正

### 4.1 首帧初始化

用户在首帧提供点、框或 mask 后，模型生成对象 mask 和 object pointer，并将其作为 conditioning frame 写入记忆。多个对象可以分别初始化，之后共享视频帧特征但保留各自的对象状态。

### 4.2 前向/反向传播

对于离线视频，模型可以从用户交互帧向前、向后传播；对于实时视频，则按帧流式处理，只保留有限历史记忆。二者共享相同的提示、记忆注意力和 mask 解码机制。

### 4.3 遮挡与离屏

视频中的对象可能暂时被遮挡、离开视野或重新出现。SAM 2 通过 no-object 分数判断当前帧是否应输出目标，同时利用历史记忆在短时遮挡后恢复 mask。实际工程中仍建议设置目标生命周期、重检测和人工/上游模型重新提示机制，避免错误记忆长期传播。

### 4.4 多目标

多目标场景通常为每个对象维护独立的提示和对象指针，再对同一帧图像特征进行复用。推理时要额外处理对象之间的 mask 重叠、对象 ID 管理、记忆容量和显存增长问题。

## 5. 训练方案与数据引擎

### 5.1 SA-V 数据集

SAM 2 配套构建了 SA-V（Segment Anything Video）数据引擎和数据集。其核心思路不是一次性人工标注所有视频，而是让模型参与标注：用户在少量帧上交互，模型传播 mask，标注结果再被人工修正并回流训练。

这种数据引擎形成了“模型辅助标注—人工修正—重新训练—更好传播”的闭环，重点覆盖视频中传统静态数据集较难覆盖的运动、遮挡、形变、出入画和长时一致性问题。

### 5.2 训练输入模拟

训练不仅使用完美的 ground-truth mask，还会模拟真实用户交互过程：

- 从真实 mask 采样正点和负点；
- 使用框作为提示；
- 将模型前一步预测作为后续输入；
- 在多个视频帧上进行提示和纠错；
- 训练多候选 mask 与 IoU 质量预测。

因此模型学习的不是“从真值 mask 直接复制结果”，而是学习在提示不完美、传播有误差、需要迭代修正的情况下继续工作。

### 5.3 多任务损失

训练目标通常包括：

- mask 的 BCE/交叉熵类损失；
- Dice 类区域重叠损失；
- IoU 或 mask 质量回归损失；
- 对象存在性/no-object 损失；
- 多帧和多步预测损失。

这些损失分别约束像素分类、区域完整性、候选质量排序、遮挡/离屏判断和时序传播能力。

## 6. 为什么 SAM2 的效果好

### 6.1 图像与视频统一建模

传统图像分割器通常只看当前帧，视频方案再额外接一个光流或跟踪器，容易产生检测、分割、跟踪之间的级联误差。SAM 2 从模型设计阶段就把图像和视频放在同一任务中：图像可以看作没有历史记忆的视频，视频则在图像分割能力上增加时序记忆。

### 6.2 记忆提供时序先验

相邻视频帧通常具有较高相关性。上一帧的 mask、对象外观和对象指针为当前帧提供了强先验，使模型在运动模糊、姿态变化和短时遮挡下不必完全从零开始识别目标。这是 SAM 2 相比逐帧独立分割器更稳定的关键原因。

### 6.3 提示驱动降低任务歧义

模型不需要在所有类别中自动猜测用户想要哪个对象，而是通过点、框或 mask 获得明确的实例级条件。正点与负点还可以表达局部排除关系，在同类对象密集、对象互相接触时尤其有效。

### 6.4 高分辨率细节和全局语义兼顾

Hiera/FPN 多尺度特征、Memory Attention 和高分辨率 mask 特征共同解决两个互相冲突的问题：既要知道对象整体是什么，又要找准像素边界。边界、孔洞、细长结构和小目标因此比只使用单一低分辨率特征更容易保留。

### 6.5 数据引擎针对真实视频难例

SA-V 的数据收集流程直接围绕视频交互和传播建立，训练样本覆盖了静态图片中不常见的运动、遮挡、镜头变化和对象消失。模型训练分布与实际视频使用方式更接近，因此 zero-shot 视频泛化能力更强。

### 6.6 迭代交互机制把一次错误变成可修正状态

当第一步 mask 不完整时，用户可以继续点击正/负点或提供新框。模型把新提示与已有 mask、记忆共同融合，而不是完全推倒重来。这个闭环让系统在复杂边界和遮挡场景中具备较好的可用性。

## 7. 与 SAM、SAM3 的关系

| 方案 | 主要提示 | 核心能力 | 是否以文本概念自动发现为主 |
|---|---|---|---|
| SAM | 点、框、mask | 单图通用实例分割 | 否 |
| SAM 2 | 点、框、mask、视频交互 | 图像分割 + 视频对象传播 | 否 |
| SAM 3 | 文本、图像示例、交互提示 | 开放词汇全实例检测/分割/跟踪 | 是 |

SAM 2 适合“我指出这个对象，请在整段视频中持续分割它”；SAM 3 更适合“请找出画面中所有符合这个概念的对象”。两者并非简单替代关系：SAM 2 的交互式实例传播和视频记忆仍然适合需要精确指定单个对象的工作流。

## 8. 推理方案

### 8.1 单图推理

```text
1. 读取图像并按模型要求缩放、归一化
2. 编码点、框或已有 mask 提示
3. 运行 Hiera 图像编码器和 FPN
4. 通过 prompt encoder + mask decoder 生成候选 mask
5. 使用 IoU 质量分数选择或排序候选
6. 输出 mask、框、面积和质量分数
```

### 8.2 视频推理

```text
1. 在首帧或关键帧输入点/框/mask
2. 编码当前帧并生成对象 mask 与 object pointer
3. 将 mask 特征写入 streaming memory
4. 对下一帧执行 Memory Attention
5. 解码当前帧 mask，并更新记忆
6. 在置信度下降、遮挡恢复或用户纠错时重新提示
```

### 8.3 工程参数

- **模型大小**：小模型适合交互和边缘设备，大模型适合离线高质量处理；
- **输入分辨率**：提高分辨率有利于小目标和边界，但显存、延迟和吞吐会下降；
- **memory 长度**：更长的记忆有助于长期一致性，但会增加注意力成本和错误累积风险；
- **重检测频率**：长视频建议周期性重提示或与专用检测器结合，避免漂移；
- **多 mask 策略**：首次点击或歧义较大时保留多个候选，后续通过质量分数和交互筛选；
- **对象数量**：多目标时复用帧级视觉特征，独立维护对象状态，并限制无效轨迹数量。

## 9. 评价指标

建议分别评价图像、视频和交互效率：

- **图像分割**：mask IoU、mask AP、边界 F-score、小目标召回率；
- **视频分割/跟踪**：J&F、Jaccard、Contour accuracy、ID switch、轨迹断裂率；
- **交互效率**：达到目标质量所需点击数、修正帧数量、每次交互延迟；
- **工程指标**：单帧延迟、视频 FPS、显存占用、首帧启动时间和长视频稳定性。

不能只看静态图像 mask AP 来判断 SAM 2 的视频能力。视频任务的核心还包括跨帧一致性、遮挡恢复、ID 稳定性和交互成本。

## 10. 局限性与部署风险

1. **不是文本检测器**：没有自然语言概念检测头，不能直接替代开放词汇检测模型。
2. **需要有效提示**：点或框落在错误对象、遮挡区域或边界附近时，结果可能不稳定。
3. **长时漂移**：错误 mask 写入记忆后可能影响后续帧，需要重提示、重检测或轨迹质量监控。
4. **小目标和快速运动**：输入分辨率不足、运动模糊或目标严重遮挡时，传播可能失败。
5. **多目标资源开销**：每个对象需要维护状态，目标数量增加会增加显存和推理成本。
6. **领域迁移**：红外、鱼眼、车载环视、工业相机和医学视频等场景应使用业务数据重新评测。
7. **部署依赖**：官方训练/开发环境面向高性能 GPU；端侧应用通常需要量化、裁剪、蒸馏或 ROI 推理。
8. **许可证与数据合规**：上线前应分别核对代码、权重、数据集和衍生标注的许可证，不应只依据论文判断商用范围。

## 11. 面向感知系统的推荐集成

对于已有检测、跟踪和分割链路的系统，推荐采用“检测器初始化 + SAM 2 精细分割/传播”的组合：

```text
视频帧
  ├─> 实时检测器 ─> 框/类别/置信度 ─> SAM 2 初始化
  ├─> 用户点/框/mask ────────────────> SAM 2 初始化
  └─> SAM 2 Memory Attention ────────> 时序 mask 和对象轨迹
                                      ↓
                         质量监控/重检测/结果融合
```

推荐职责划分：

- 用实时检测器解决固定类别、高频、低延迟的目标发现；
- 用 SAM 2 将框或少量交互转成精细 mask，并传播到后续视频帧；
- 在 mask 质量下降、对象长时间不可见或 ID 不稳定时触发重检测；
- 将 mask 作为占用、可行驶区域、目标轮廓或自动标注的下游输入；
- 对每条轨迹记录 mask 质量、可见性、面积变化、速度和最近一次纠正帧。

## 12. 结论

SAM 2 的强项可以归纳为六点：

1. 用点、框和 mask 提示明确指定目标实例；
2. 用 Hiera/FPN 多尺度特征兼顾语义和边界；
3. 用 Mask Decoder 直接生成高质量像素级结果；
4. 用 Memory Attention 融合当前帧与历史对象状态；
5. 用 Memory Encoder 将 mask 和视觉信息压缩为流式记忆；
6. 用 SA-V 数据引擎和交互式训练覆盖真实视频难例。

因此，SAM 2 的核心竞争力不是单帧“分得更漂亮”这么简单，而是把**提示理解、精细分割、时序传播和交互纠错**组合成了统一系统。对于自动驾驶或其他感知系统，最稳妥的方案通常不是让 SAM 2 独立承担所有检测任务，而是让专用检测器负责发现和实时性，让 SAM 2 负责精细轮廓、视频传播和交互式修正。
