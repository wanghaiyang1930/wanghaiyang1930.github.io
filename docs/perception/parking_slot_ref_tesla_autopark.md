# Tesla Vision Autopark - 基于纯视觉的自动泊车系统

## 概述

Tesla Vision Autopark是特斯拉开发的基于纯视觉（camera-only）的自动泊车系统，完全移除了超声波传感器（USS），仅依赖8个外部摄像头和神经网络实现泊车功能。系统使用占用网络（Occupancy Networks）技术，通过体素（voxel）网格对车辆周围环境进行3D重建。核心架构包括Transformer模型，将多个摄像头的2D图像数据融合成统一的3D表示，并结合时序信息计算占用流（occupancy flow）来预测移动物体的速度。配备AMD处理器的车辆可显示高保真3D重建视图，Intel处理器车辆则显示2D俯视图。系统支持倒车入库和平行泊车，但目前不支持前向停车和斜向车位。

## 技术方案

**核心技术架构**：

1. **占用网络Pipeline（5个阶段）**：
   - 图像输入：8个外部摄像头
   - 特征提取：Featurizers提取纹理和边缘
   - 空间变换：Transformer的空间注意力机制将8个摄像头的2D特征投影融合为统一3D表示
   - 时序对齐：融合连续时间点的3D表示捕捉运动
   - 反卷积：将融合数据转换为每个体素的预测

2. **体素网格系统**：
   - 每个体素预测：占用状态、速度矢量和物体类型
   - 关键区域精度：可达10cm
   - 支持部分占用的子体素分割

3. **表面确定系统**：
   - 独立AI模型分析摄像头图像
   - 预测表面属性：高程、几何形状、可导航性、材质
   - 识别特征：车道线和坑洼
   - 生成带属性标签的3D表面网格

4. **统一世界模型**：
   - 占用系统和表面系统协同工作
   - 为路径规划提供三维语义丰富的环境理解

5. **硬件要求**：
   - 需要HW3或更高版本
   - AMD处理器：支持高保真3D重建
   - Intel处理器：提供2D俯视图

6. **专利技术**：Tesla已申请"基于视觉的高保真占用确定和辅助泊车应用的人工智能建模技术"专利

## 优点

- 完全基于视觉，无需超声波传感器，降低硬件成本和维护复杂度
- 比旧的USS系统更快速、更精确，可以停入仅比车辆最大宽度略宽的车位
- 在困难的平行泊车场景表现出色，能在狭窄空间内精确停车，与相邻车辆保持1-2英寸距离
- 允许驾驶员选择具体停车位置，提供更多控制权
- 利用占用网络进行3D环境重建，可以识别物体类型、位置和运动速度
- 使用自适应分辨率，关键区域可将体素精度提高到10厘米
- 基于Transformer架构融合空间和时序信息，提供语义丰富的环境理解
- 可通过OTA升级持续改进功能

## 缺点

- 泊车速度较慢，过于谨慎，即使在空旷停车场也会频繁自我修正
- 仅支持倒车入库，无法前向驶入车位或处理斜向停车位
- 在无标线或标线模糊的停车场表现不稳定，可能导致停车歪斜
- 系统按停车线居中而非按相邻车辆居中，可能停得过于靠近邻车导致无法开门
- 在无明确标记的区域，即使有足够上下文信息也可能无法识别车位
- 无法检测儿童、行人、骑车者、动物或移动物体
- 无法检测过高、过低、过近或过远的物体
- 存在安全隐患：德国法院委托的专家报告显示系统频繁无法检测障碍物，可靠性低于竞争对手
- 目前不支持右舵驾驶市场（英国、澳大利亚、日本等）
- 需要Enhanced Autopilot或Full Self-Driving套件，增加使用成本

## 监督方法

Tesla采用混合监督学习方法训练Vision系统。主要监督方式包括：

1. **LiDAR传感器标注**：在测试阶段生成ground truth数据，提供精确的距离和3D几何信息

2. **摄影测量技术**（photogrammetry）：从多视角图像重建3D结构

3. **数据关联**：将LiDAR和摄影测量数据与实际车辆的摄像头图像关联，训练模型学习深度估计和表面特征识别

4. **影子模式**（Shadow Mode）：
   - 在真实车队中收集数据
   - 当车辆进入特定地理围栏区域时，系统在后台运行并标记为模拟无监督数据
   - 即使由人类控制也能收集训练样本

5. **车队数据积累**：利用全球车队的实际驾驶场景持续积累标注数据

这种方法让纯视觉系统学习推断深度、形状、运动和上下文信息，无需在量产车上安装LiDAR。

## 训练数据

**截至2026年5月，Tesla FSD（监督模式）车队累计行驶里程**：超过100亿英里（10 billion miles）

**里程碑时间线**：
- 2021年：600万英里
- 2022年：8000万英里
- 2023年：6.7亿英里
- 2024年：22.5亿英里
- 2025年：42.5亿英里
- 2026年3月：84亿英里
- 2026年5月：突破100亿英里

**数据来源**：
- 全球用户车队在主动FSD模式和影子模式下的行驶数据
- 涵盖各种真实驾驶场景
- 数据通过车队聚合后输入神经网络训练流程

**技术演进**：
- FSD v12采用单一端到端网络后性能大幅提升
- 马斯克在2026年1月表示，实现安全的无监督自动驾驶大约需要100亿英里的训练数据
