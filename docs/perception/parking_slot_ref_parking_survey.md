# 停车位检测技术综述

## 概述

停车位检测是自动泊车系统的关键第一步。现代方法主要分为两大类：传统计算机视觉方法和深度学习方法。传统方法使用霍夫变换、边缘检测和聚类技术，而深度学习方法（包括目标检测、图像分割、回归和图神经网络）已显著提高了检测性能。从传感器角度看，主要包括基于图像传感器的标记线识别和基于测距传感器（超声波、激光雷达、毫米波雷达）的自由空间识别。未来趋势是融合图像传感器和测距传感器的互补特性，以实现更鲁棒的目标停车位置指定。检测流程通常包括：预处理、特征提取（低级特征如角点颜色，高级特征如形状排列）、预测模块（检测/分割/分类）和后处理（几何规则或模板匹配）。

## 技术方案

**四大类深度学习方法**：

1. **目标检测（15项研究）**：
   - 单阶段：YOLO系列、FCOS，实现快速推理23-150 FPS
   - 多阶段：区域提议网络+分类细化，精度更高但较慢3-60 FPS

2. **图像分割（8项研究）**：
   - 使用U-Net、Mask R-CNN等架构分割停车位线条
   - 后处理结合形态学操作和霍夫变换

3. **回归方法（2项研究）**：
   - 直接预测标记点坐标
   - 通过模板匹配推断完整车位

4. **图神经网络（1项研究）**：
   - 首次应用GNN建模标记点关系

**传感器融合方面**：
- AVM/LiDAR融合用于SLAM和快速闭环
- 激光雷达点云强度检测垂直停车位标记线
- 紧耦合偏振激光雷达和IMU实现鲁棒识别

**评估指标**：
- 检测任务：精度和召回率（阈值：12像素距离内且朝向10度内）
- 速度评估：FPS
- 分割任务：mIOU

**硬件平台**：
- GPU：Nvidia Titan X/Xp, GTX 1080/Ti, RTX 2080 Ti/3090
- 嵌入式：Qualcomm 820a达101 FPS, Nvidia Drive AGX Xavier达17 FPS
- CPU：Intel Xeon, i7/i9

**未来方向**：
- 更多样化和综合性数据集（包括天气、损坏车位、视频数据）
- 针对低计算能力嵌入式系统的优化
- 解决车载嵌入式系统限制

## 优点

- 深度学习方法相比传统方法具有更强的鲁棒性和准确性，在PS2.0数据集上已达到99%以上的精度
- 单阶段检测器（如YOLO系列）可实现实时性能，在嵌入式硬件上达到17-150 FPS
- 图像传感器可准确识别停车位标记线，提供精确的位置和方向信息
- 测距传感器（激光雷达、超声波）在低光照环境下表现鲁棒，可直接通过3D信息判断占用状态
- 传感器融合方法结合图像和测距传感器的互补特性，能够同时检测标记线和自由空间
- 多边形表示（如HPS-Net）可从不同角度检测停车位，输出四个顶点坐标而非简单边界框
- 图神经网络（GNN）可建模标记点之间的关系，通过多头注意力机制进行特征聚合

## 缺点

- 传统方法在光照变化、复杂环境和多样化停车位类型下缺乏鲁棒性
- 现有数据集（如PS2.0）规模有限，多样性不足，导致泛化能力低，无法充分代表真实世界中的光照变化、遮挡和天气条件
- 深度学习方法在不同场景下性能差异较大：室内场景F1得分0.86，铺装地面0.91，相比标准数据集的0.99有明显下降
- 现代停车位呈现多种挑战：不同形状（倾斜、垂直、平行）、颜色变化、光照条件（阴影、昼夜）、车辆或障碍物遮挡、标记线损坏
- 超声波传感器需要扫描完整停车位才能检测，无法检测连续多个车位，分类能力差
- 多阶段方法虽然精度较高但速度较慢（3-60 FPS），难以满足实时性要求
- 嵌入式车载系统计算能力有限，模型优化和部署面临挑战
- 26项研究中仅9项包含占用状态检测，功能完整性不足
- 分割方法的mIOU指标在PSV数据集上仅46-68%，像素级精度有待提高

## 监督方法

监督式学习为主流方法。标注方式包括：

1. **标记点分类**：将标记点分为7类，包括不同方向类型

2. **目标检测标注**：使用边界框标注停车位或标记点

3. **分割标注**：像素级掩码标注停车位线条与背景

4. **回归标注**：
   - 直接标注标记点坐标
   - 输出网格化矩阵（如16×16×6，包含坐标、方向、置信度）

5. **多边形顶点标注**：
   - 标注停车位四个顶点的鸟瞰图坐标
   - 使用polygon-corner GIoU损失函数优化顶点位置、处理朝向并识别入口线

**其他方法**：
- 部分研究提出半监督学习方法以减少人工标注成本
- 激光雷达方法利用点云强度检测标记线
- IMU紧耦合实现自动标注

## 训练数据

**主流数据集规模**：

1. **PS2.0**（同济大学，2018）：
   - 训练集：9,827张
   - 测试集：2,338张
   - 分辨率：600×600
   - 拼接鸟瞰图
   - 使用率：26项研究中17项使用

2. **SNU数据集**（2020）：
   - 训练集：18,299张
   - 测试集：4,518张
   - 分辨率：768×256
   - 未拼接鱼眼图像
   - 多样性更高但利用不足（仅2项研究使用）

3. **PSV数据集**（同济）：
   - 训练集：2,550张
   - 验证集：425张
   - 测试集：1,274张
   - 分辨率：640×480
   - 主要用于分割任务

4. **VPSD**（Valeo内部数据集）：
   - 规模未公开
   - 包含多种场景

5. **CRPS-D**（新型大规模数据集）：
   - 包含多种光照分布
   - 不同天气条件
   - 挑战性停车位变体

6. **其他数据集**：
   - CARPK和PKLot作为源数据集
   - 包含1,257张图像和10,000+标注多边形
   - COCO JSON格式

研究表明现有数据集在规模和真实世界噪声表示方面存在局限，2024年推出了新的大规模数据集以解决这些问题。
