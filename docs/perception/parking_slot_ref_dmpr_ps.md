# DMPR-PS: 基于方向性标记点回归的停车位检测方法

## 概述

DMPR-PS采用方向性标记点回归(Directional Marking-Point Regression)方法进行停车位检测。核心思想是先检测带有方向信息的标记点,然后将这些标记点组合成完整的停车位。该方法将停车位检测问题分解为两个阶段:1)方向性标记点检测;2)基于标记点的停车位组装。模型输出包含6个通道的特征图:置信度、标记点形状、X/Y偏移量、以及方向的余弦和正弦值。通过这种方式将角度表示为余弦-正弦对,避免了0°/360°的不连续性问题。

## 技术方案

**模型架构**：DirectionalPointDetector
- 输入：3通道RGB图像(512×512)
- 输出：6通道特征图(16×16)
- 网络深度因子：默认为32

**特征图通道定义**：
- 通道0：置信度
- 通道1：标记点形状
- 通道2：X偏移
- 通道3：Y偏移
- 通道4：方向余弦
- 通道5：方向正弦

**损失函数**：自定义加权梯度L2损失
- loss = (prediction - objective)^2
- 使用梯度掩码对不同通道进行加权

**训练配置**：
- 优化器：Adam，学习率1e-4
- 批次大小：24
- 训练轮数：20轮

**检测阈值**：
- 置信度：0.117（精确率99.56%，召回率99.58%）
- 边界阈值：0.05
- 距离阈值：对应10像素
- 角度阈值：30度

**停车位组装参数**：包括垂直/水平槽距离范围、短/长分隔符长度、桥接角度差、分隔符角度差等几何约束条件。

## 优点

- 采用标记点回归而非直接检测停车位,将复杂问题分解为更简单的子问题,降低了检测难度
- 使用余弦-正弦对表示方向信息,避免了角度表示的不连续性问题,提高了模型训练的稳定性
- 通过sub-pixel级别的偏移量回归实现精确定位,提高了标记点的定位精度
- 支持多种停车位类型(垂直、平行、斜向)的检测
- 在ps2.0数据集上取得了较高的检测性能,整体精确率99.54%,召回率98.89%
- 采用多通道特征图输出,同时预测位置、形状和方向等多个属性,信息表达更丰富

## 缺点

- 依赖高质量的标记点标注数据,需要专门的标注工具(MarkToolForParkingLotPoint)进行数据准备,标注成本较高
- 需要手动设置多个阈值参数(置信度阈值、距离阈值、角度阈值等),参数调优较为复杂
- 两阶段检测流程(标记点检测+停车位组装)增加了系统复杂度,推理时间相对较长
- 输入图像需要resize到固定尺寸(512×512),可能损失部分原始图像信息
- 特征图尺寸较小(16×16),对于大尺寸图像可能存在分辨率不足的问题
- 代码实现中使用了自定义的加权梯度L2损失,训练过程需要精心设计损失权重

## 监督方法

完全监督学习。使用JSON格式标注文件,每个标记点包含5个值：[x, y, direction_x, direction_y, type]。

**标注流程**：
- 标记停车位边界的关键点
- 指定每个点的方向信息和类型
- 标注坐标经过归一化处理(范围[0,1])
- 方向信息转换为atan2角度表示

**训练损失计算**：
- 使用带权重的L2损失
- 只在实际存在标记点的位置计算形状、偏移和方向通道的损失
- 背景像素仅贡献置信度通道的损失

提供专门的标注工具directional_point分支版本的MarkToolForParkingLotPoint用于自定义数据标注。

## 训练数据

**数据集**：Tongji Parking-slot Dataset 2.0 (ps2.0)
- 总图像数：12,165张
- 训练集：9,827张
- 测试集：2,338张
- 图像来源：车载四个低成本鱼眼相机合成的环视图像

**数据增强策略**：
- 每张原始图像以5度为间隔进行旋转增强(5°, 10°, 15°...最多到355°)
- 理论上每张图像可生成最多72个旋转变体
- 实际数量取决于边界和重叠验证的通过情况

**测试集场景分布**：
- 室内停车场：226张
- 室外正常光照：546张
- 室外雨天：244张
- 室外阴影：1,127张
- 室外路灯：147张
- 室外斜向：48张
