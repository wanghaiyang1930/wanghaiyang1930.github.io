# 基于环视图像的深度学习停车位检测综述

## 概述

这是一篇2023年发表在MDPI Sensors期刊的综述论文，系统性地回顾了26篇使用深度学习进行停车位检测的研究工作。论文将现有方法分为四大类：目标检测方法（15篇，包括单阶段和多阶段检测）、图像分割方法（8篇）、回归方法（3篇）和图神经网络方法（1篇）。研究主要针对环视图像或鱼眼相机图像进行停车位标记点和停车位线的检测，是该领域首个包含图神经网络方法的系统性综述。

## 技术方案

论文系统性地分类了深度学习停车位检测的主要方法：

1. **目标检测方法（15篇）**：
   - 单阶段检测器：YOLOv2/v3/FCOS/CenterNet等，配合AlexNet/VGG16/ResNet/MobileNetV2/DenseNet101等骨干网络，速度快（23-150 FPS）
   - 多阶段检测器：Faster R-CNN等，精度更高但速度较慢（3-60 FPS）

2. **图像分割方法（8篇）**：U-Net、Mask R-CNN、PSPNet、堆叠沙漏网络等，后处理包括骨架化和霍夫变换

3. **回归方法（3篇）**：输出16×16特征图预测坐标、形状、角度和置信度

4. **图神经网络方法（1篇）**：三阶段流程（特征提取+标记点检测→多头注意力GNN→入口线判别器）

关键技术包括：CBAM注意力机制、特征金字塔网络(FPN)、自校准卷积、双检测器架构、通道注意力、动态权重损失、位置注意力块等。

训练技巧：288×288输入、动态学习率0.92、权重衰减0.0015、批次大小160、数据增强(裁剪0.2)、IOU阈值0.7等。

## 优点

- 单阶段目标检测方法（如YOLO系列）速度快，适合实时应用，部分方法达到134 FPS的实时处理速度
- 多阶段方法精度更高，在ps 2.0数据集上可达99.77%的精确率和召回率
- 图像分割方法能够精确提取停车位线特征，适合复杂场景
- 部分方法模型体积小（如SPFCN仅2.39MB），适合嵌入式系统部署
- 采用注意力机制（CBAM、位置注意力等）、特征金字塔网络(FPN)、自校准卷积等先进技术提升了检测性能
- 图神经网络方法能够建模标记点之间的关系，提供新的解决思路
- 多种骨干网络可选（VGG16、ResNet、MobileNetV2、DenseNet101等），可根据精度和速度需求灵活选择

## 缺点

- 仅9/26的研究包含占用检测功能，而这对自动驾驶和实际应用很重要
- ps 2.0数据集已接近性能瓶颈（多数方法达99%以上精度），难以区分不同方法的实际性能差异
- 现有数据集缺少多样化的光照条件、恶劣天气、损坏车位、复杂停车场设计等挑战性场景
- 缺乏视频序列数据，无法评估时序一致性和跟踪能力
- 多阶段检测方法计算成本较高，不适合资源受限的嵌入式系统
- SNU数据集虽然更具挑战性（精度仅87.75%）但采用率很低，仅有2项研究使用
- 部分研究使用的私有数据集规模过小（如仅493张图片），泛化能力存疑
- 针对嵌入式系统的算法优化和硬件加速研究仍不足

## 监督方法

综述中的所有26篇研究均采用监督学习方法，依赖标注数据集进行训练。论文未按监督范式（全监督/弱监督/半监督/无监督）对方法进行分类，而是按检测方法论（目标检测、分割、回归、图神经网络）分类。

标注内容包括：
- 停车位标记点的坐标
- 标记点类别（7类标记点分类）
- 停车位线的像素级分割
- 停车位的朝向角度等

评估标准为：当检测到的关键点距离真实值12像素以内且朝向角度误差在10度以内时判定为真阳性。

## 训练数据

三个主要基准数据集：

1. **ps 2.0数据集**（同济大学，2018）：
   - 12,165张图像（训练集9,827张，测试集2,338张）
   - 600×600分辨率，鸟瞰图
   - 包含室内外三种停车场类型
   - 是使用最广泛的数据集（17项研究使用）

2. **PSV数据集**（2018）：
   - 4,249张图像（训练集2,550张，验证集425张，测试集1,274张）
   - 640×480分辨率

3. **SNU数据集**（首尔国立大学，2020）：
   - 22,817张图像（训练集18,299张，测试集4,518张）
   - 768×256分辨率，侧视图
   - 场景更多样化但采用率低

73%的研究仅使用单一数据集，27%使用两个数据集，另有6项研究使用私有数据集。
