# 苏轼

苏轼有一个好朋友叫王巩，长得非常帅，苏轼就给他取了一个外号叫“琢玉郎”，就是白面书生的意思。

九日次韵王巩
闻道郎君闭东阁，且容老子上南楼，
相逢不用忙归去，明日黄花蝶也愁。

后来苏轼被贬，王巩也受到牵连流放岭南，苏轼心里过意不去，觉得很对不起朋友。他很担心王巩，可又不敢主动写信，生怕王巩受到更多牵连。
倒是王巩，人还在流放路上，就一封又一封的主动给苏轼写信，完全没有疏远的意思。苏轼看王巩的心态还挺好，就放心了，但是苏轼并不知道，王巩的两个儿子都死在了流放的路上，凄惨至极。

三年后，王巩刑满被获准还京，又过了几年苏轼也获得赦免，这对阔别7年，差点生死相隔的好友，终于阔别详见。
当苏轼知晓了一切，他不知道怎么安慰王巩，可王巩脸色淡然，微笑着请苏轼听曲。唱曲的是王巩的一位歌姬，名字叫宇文柔奴，流放岭南时，她一直配置王巩身边。
苏轼就旁敲侧击的跟柔奴打听，说你们在岭南过的不好吧？结果没想到，柔奴却微微一笑道：此心安处，便是吾乡。

苏轼颇为震动，便挥笔写下了名篇《定风波》：
常羡人间琢玉郎，天应乞与点酥娘。尽道清歌传皓齿，风起，雪飞炎海变清凉。
万里归来颜愈少，微笑，笑时犹带岭梅香。试问岭南应不好，却道，此心安处是吾乡。
