# 上采样（Upsampling）教程

上采样的作用是增加特征图的空间分辨率。理解它需要分清三个问题：

1. 输出尺寸如何变化？
2. 新增位置的数值从哪里来？
3. 哪些部分有可学习的参数？

本文从零介绍最近邻插值、双线性插值、转置卷积、插值加卷积和 Pixel Shuffle，并说明坐标对齐、输出尺寸和棋盘格伪影等实现细节。

---

## 1. 上采样是什么？

对于采用 `NCHW` 布局的二维特征图：

```text
输入：[batch, channels, 32, 32]
输出：[batch, channels, 64, 64]
```

高、宽各扩大 2 倍，空间位置数量增加到原来的 4 倍。普通插值不改变 batch 和通道数，而包含卷积的上采样模块可以同时调整通道数。

典型应用包括语义分割中的解码器、图像超分辨率、生成模型，以及多尺度特征融合。

需要注意：

> 尺寸变大，不等于丢失的信息被恢复。

固定插值只是按照规则计算新增位置；可学习的上采样根据训练数据预测高分辨率表示。即使生成了合理的细节，也不能保证它们就是原始真实细节。

## 2. 最近邻插值

### 2.1 核心原理

把输出位置映射到输入坐标，然后选取附近的一个输入像素值，不对多个像素加权混合。

例如，将一个 `2 × 2` 矩阵放大 2 倍：

```text
1  2             1  1  2  2
                 1  1  2  2
3  4      →      3  3  4  4
                 3  3  4  4
```

### 2.2 特点与适用场景

- 没有可学习参数。
- 不会产生输入中不存在的新数值。
- 图像放大后容易出现块状边缘。
- 适合离散类别标签的缩放，避免混合类别编号。

例如，标签中的 `0` 和 `2` 是类别编号，不应通过线性插值得到代表另一个类别的 `1`。对于连续概率图或网络内部特征，则需要根据模型设计选择插值方式。

PyTorch 的 `nearest` 和 `nearest-exact` 使用不同的坐标取整约定。复现已有模型时应保持原有模式，而不是仅凭名称把它们视为完全等价。

## 3. 双线性插值

### 3.1 四个邻居加权求和

目标位置映射回输入后，如果位于四个像素之间：

```text
v00 ───── v01
 │    •    │
v10 ───── v11
```

设水平相对距离为 α，竖直相对距离为 β，二者均在 `[0, 1]` 内，则输出为：

```text
value = (1 - α)(1 - β)v00
      + α(1 - β)v01
      + (1 - α)βv10
      + αβv11
```

也可以拆成两步：

```text
top    = (1 - α)v00 + αv01
bottom = (1 - α)v10 + αv11
value  = (1 - β)top + βbottom
```

也就是先沿水平方向插值，再沿竖直方向插值。

例如：

```text
1  3
5  7
```

方格正中心处 `α = β = 0.5`，所以插值结果为：

```text
value = (1 + 3 + 5 + 7) / 4 = 4
```

这个例子说明任意给定坐标上的插值计算，不意味着每次缩放后的输出网格都恰好包含这个正中心位置。

### 3.2 特点

- 没有可学习参数，对各通道独立进行空间插值。
- 相比最近邻，通常产生更平滑的过渡。
- 平滑不等于恢复细节，边缘可能变得模糊。
- 对输入数值可求梯度，因此可以放进神经网络参与反向传播。

### 3.3 `align_corners`：像素网格如何对齐？

插值不只有“如何加权”的问题，还有“输出位置对应输入的哪个坐标”的问题。

以一维为例，输入长度为 `input_size`，显式指定的输出长度为 `output_size`，输出索引为 `index`。

当 `align_corners=True` 且 `output_size > 1` 时，首尾像素的中心对齐：

```text
input_position = index * (input_size - 1) / (output_size - 1)
```

当 `align_corners=False` 时，对齐的是整个像素区域的外边界，采用半像素偏移：

```text
input_position = (index + 0.5) * input_size / output_size - 0.5
```

例如长度从 2 放大到 4：

```text
align_corners=True：  0, 1/3, 2/3, 1
align_corners=False：-0.25, 0.25, 0.75, 1.25
```

对于超出输入范围的坐标，线性插值使用边缘值处理。

实践中需要注意：

- 两种设置即使输出形状相同，数值也可能不同。
- 训练、推理和模型复现时应保持设置一致。
- `align_corners` 适用于线性系列插值模式，不用于最近邻模式。
- 上面的公式针对显式输出尺寸；使用浮点 `scale_factor` 时，还需要考虑输出尺寸取整和 `recompute_scale_factor` 的影响。

## 4. 转置卷积（Transposed Convolution）

### 4.1 直观理解：输入向输出区域贡献数值

转置卷积通过可学习的卷积核生成输出。可以把它理解为：每个输入值向一块输出区域贡献数值，重叠位置相加。

考虑一个一维例子，忽略偏置：

```text
输入：[a, b]
卷积核：[p, q, r]
stride = 2
padding = 0
```

第一个输入的贡献：

```text
ap  aq  ar   0   0
```

第二个输入的贡献向右偏移两个位置：

```text
 0   0  bp  bq  br
```

相加得到：

```text
ap  aq  ar+bp  bq  br
```

二维情况下，每个输入值贡献一块二维区域；多个输入通道的贡献也会按照卷积权重累加到输出通道。

另一种等价理解是在输入位置之间插零，再进行适当的卷积和边界处理。它主要是理解计算的方式，实际实现不一定显式构造插零张量。

### 4.2 为什么叫“转置”，不是“逆”？

忽略偏置，把固定权重的普通卷积写成矩阵形式：

```text
output = A · input
```

对应的转置操作使用：

```text
result = Aᵀ · output
```

但通常：

```text
AᵀA ≠ I
```

所以转置卷积不是普通卷积的逆运算，不能保证恢复原始输入。这里转置的是整个卷积线性算子，而不只是对一个小卷积核矩阵交换行列。

在实际模型中，转置卷积的权重通常独立训练，不要求和编码器中的某个卷积层共享。

### 4.3 输出尺寸公式

对高度方向：

```text
H_out = (H_in - 1) * stride
      - 2 * padding
      + dilation * (kernel_size - 1)
      + output_padding
      + 1
```

宽度方向同理，各参数可以按对应维度分别取值。

例如：

```text
H_in = 32
stride = 2
padding = 1
dilation = 1
kernel_size = 4
output_padding = 0

H_out = (32 - 1) * 2 - 2 + 3 + 1 = 64
```

`output_padding` 用于解决输出尺寸的歧义：带步长的普通卷积可能把不同输入尺寸映射到同一个输出尺寸，因此转置方向需要额外的信息来确定目标尺寸。

> `output_padding` 不表示在最终输出外面简单补一圈零，也不会让转置卷积变成真正的逆运算。

### 4.4 棋盘格伪影

不同输出位置可能接收到不同数量或强度的卷积核贡献。

当卷积核大小不能被步长整除时，容易出现结构性的不均匀重叠；二维情况下，这种差异可能表现为棋盘格纹理。

例如 `kernel_size=3, stride=2` 的重叠覆盖不均匀，而 `kernel_size=4, stride=2` 可以减少这种由覆盖次数造成的问题。

但需要注意：

> 卷积核大小能被步长整除，并不保证完全消除棋盘格伪影；学习到的权重同样会影响结果。

## 5. 插值 + 卷积

这种方式把空间放大和特征学习分开：

```text
低分辨率特征
    ↓ 最近邻或双线性插值
高分辨率特征
    ↓ 普通卷积
高分辨率输出
```

插值负责确定空间尺寸；卷积负责学习局部特征、融合通道，以及调整输出通道数。

### 优点

- 输出空间尺寸容易控制。
- 将固定几何缩放和可学习特征变换分离。
- 可以减少转置卷积中由不均匀重叠引起的棋盘格问题，但并非绝对无伪影。

### 代价

卷积在放大后的网格上执行。普通卷积的主要计算量与以下量成正比：

```text
H_out * W_out * C_in * C_out * kernel_height * kernel_width
```

保持通道数、卷积核等参数不变，高、宽各放大 `scale` 倍后，这层卷积的主要计算量约增加到低分辨率卷积的 `scale²` 倍，中间特征的存储量也会增加。

这不是所有上采样模块之间固定的计算量比值；实际比较还要看通道数、核大小和具体实现。

## 6. Pixel Shuffle：把通道变成空间位置

### 6.1 核心原理

Pixel Shuffle 不做插值，而是重新排列张量元素：

```text
[N, C_out * scale², H, W]
                 ↓
[N, C_out, H * scale, W * scale]
```

例如：

```text
[N, 256, 32, 32]
        ↓ PixelShuffle(2)
[N,  64, 64, 64]
```

空间位置数量增加 4 倍，通道数减少为四分之一，总元素数保持不变。

对于单个输出通道，输入某个空间位置的四个通道值：

```text
[a, b, c, d]
```

可以重排成对应的 `2 × 2` 空间区域：

```text
a  b
c  d
```

### 6.2 可学习部分在哪里？

Pixel Shuffle 本身没有可学习参数。常见模块先用卷积预测子像素所需的通道，再执行重排：

```text
低分辨率特征
    ↓ 卷积：输出 C_out * scale² 个通道
低分辨率、多通道特征
    ↓ Pixel Shuffle
高分辨率输出
```

这样可以让较多特征计算保留在低分辨率空间，在最后阶段才转换为空间分辨率。ESPCN 超分辨率方法采用了这一设计思路。

实现时必须保证送入 Pixel Shuffle 的通道数能被 `scale²` 整除。它本身只是重排，不会自动创造额外信息；输出质量来自前面的可学习网络。

## 7. PyTorch 实现对照

下面三个模块的目标形状相同：

```text
[2, 64, 32, 32] → [2, 32, 64, 64]
```

```python
import torch
from torch import nn

features = torch.randn(2, 64, 32, 32)

resize_conv = nn.Sequential(
    nn.Upsample(
        scale_factor=2,
        mode="bilinear",
        align_corners=False,
    ),
    nn.Conv2d(64, 32, kernel_size=3, padding=1),
)

transpose_conv = nn.ConvTranspose2d(
    64,
    32,
    kernel_size=4,
    stride=2,
    padding=1,
)

subpixel_conv = nn.Sequential(
    nn.Conv2d(64, 32 * 2**2, kernel_size=3, padding=1),
    nn.PixelShuffle(upscale_factor=2),
)

for module in (resize_conv, transpose_conv, subpixel_conv):
    output = module(features)
    assert output.shape == (2, 32, 64, 64)
    print(output.shape)
```

按尺寸公式，三次输出均应为：

```text
torch.Size([2, 32, 64, 64])
```

它们输出形状相同，但参数组织、计算过程和输出数值不同，不能直接互换并期待结果不变。

### 与另一张特征图对齐

在跳跃连接或多尺度融合中，输入经过多次下采样后可能产生尺寸取整，因此“乘 2”不一定恰好匹配另一张特征图。

需要严格对齐空间尺寸时，可以直接使用目标特征图的形状：

```python
import torch
import torch.nn.functional as F

features = torch.randn(2, 64, 16, 16)
reference = torch.randn(2, 64, 31, 31)

upsampled = F.interpolate(
    features,
    size=reference.shape[-2:],
    mode="bilinear",
    align_corners=False,
)

assert upsampled.shape == reference.shape
fused = upsampled + reference
```

这里插值只匹配空间尺寸。若要逐元素相加，还需要保证 batch 和通道维度兼容；如果按通道拼接，则通道数可以不同。

## 8. 方法对比与选择

| 方法 | 可学习部分 | 新位置如何产生 | 主要注意事项 |
| --- | --- | --- | --- |
| 最近邻插值 | 无 | 选取一个输入值 | 块状边缘、坐标取整约定 |
| 双线性插值 | 无 | 四邻域加权求和 | 平滑、坐标对齐设置 |
| 转置卷积 | 卷积权重 | 输入向输出区域贡献并叠加 | 输出尺寸、棋盘格伪影 |
| 插值 + 卷积 | 后续卷积 | 固定放大后学习特征 | 高分辨率卷积开销 |
| 卷积 + Pixel Shuffle | 前置卷积 | 预测子像素通道后重排 | 通道数必须满足重排条件 |

可以把以下原则作为设计起点，而不是绝对规则：

- 缩放离散类别标签时，使用最近邻以保留类别值。
- 需要简单的连续特征缩放时，可以从双线性插值开始。
- 希望分离尺寸控制和特征学习时，可以考虑插值加卷积。
- 使用转置卷积时，检查输出尺寸和不均匀重叠问题。
- 超分辨率或希望将更多计算保留在低分辨率空间时，可以考虑卷积加 Pixel Shuffle。
- 复现模型时，应优先遵守原实现的模式、参数和坐标约定。

## 9. 总结

用四句话建立直觉：

1. 最近邻和双线性插值：按照固定规则，从旧位置计算新位置。
2. 转置卷积：每个输入向一块输出区域贡献数值，重叠部分求和。
3. 插值加卷积：先确定空间尺寸，再学习高分辨率特征。
4. 卷积加 Pixel Shuffle：先在通道中预测子像素，再把通道重排为空间。

理解上采样的关键，不是只记住“把宽高扩大”，而是同时理解尺寸变换、数值生成和参数学习之间的关系。
